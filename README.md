# 卐 SWASTIK GOLD JALORE (SWASTIK_GOLD_01)
## Universal International Bullion Live Rates Portal & Mobile App Engine

This repository contains the complete codebase for **Swastik Gold Jalore**, including:
1. **Live Customer Web App (`index.html`)**: Mobile-first live rate app with startup pop-up announcement modal and live rate cards.
2. **Customer PC Live Rates Website (`website.html`)**: Full-width live rates display portal for website visitors.
3. **PC Operator Control Desk (`pc-client.html`)**: Standalone PC operator panel for product renames, individual buy/sell hide toggles, master hide/freeze, customer PIN/password approval, and broadcast announcements.
4. **Direct Stream Server Engine (`server.js`)**: 100ms real-time proxy streaming directly from Sundha Gold live API (`bcast.sundhagold.com:7768`).
